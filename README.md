## 🌟 О проекте

**TensorMind** — это комплексный тренажёр полного цикла для глубокого освоения теории и практики машинного обучения. Платформа объединяет академическую строгость математического аппарата (формулы в нотации KaTeX), реальное написание кода прямо в браузере (Python и SQL) и передовые когнитивные методики запоминания (интервальное повторение на базе FSRS).

Приложение работает **100% клиентски и автономно** без необходимости постоянного интернет-соединения: все данные, прогресс, сохранённый код и карточки хранятся в браузере через IndexedDB и LocalStorage.

## ✨ Ключевые возможности

- 📖 **22 углубленных модуля** — от фундаментального Python (GIL, модель памяти, генераторы) и матстатистики до LLM Alignment (DPO, GRPO), квантования нейросетей (GGUF, AWQ) и ML System Design.
- ⚡ **Встроенная IDE с реальным запуском (Python 3 & SQL)** — запуск решений прямо в браузере (через Skulpt и AlaSQL) с автоматической проверкой на наборах тестов (`AC`, `WA`, `TLE`, `RE`, `CE`).
- 🧠 **Интеллектуальные карточки с интервальным повторением (FSRS v5)** — алгоритм Free Spaced Repetition Scheduler прогнозирует оптимальный интервал повторения для долгосрочного запоминания формул и концептов.
- 🏆 **Спидран / Блиц-режим** — скоростные сессии ответов на вопросы с таймером и комбо-множителями очков.
- 📖 **Интерактивный глоссарий** — справочник терминов с формулами, описанием практического назначения и поиском по категориям (ML, Deep Learning, Математика, Python & System, MLOps).
- 🎮 **Динамическая геймификация и система наград** — стрики дней, уровни, достижения и честная система штрафов при подглядывании эталонного решения.
- 🌐 **Двуязычный интерфейс (RU / EN)** — мгновенное переключение языка всей платформы, уроков и задач.
- 🎨 **Современный Glassmorphism UI** — адаптивный дизайн с поддержкой темной и светлой темы.

## 💻 Интерактивная среда исполнения кода

В платформу интегрирован полнофункциональный тестирующий движок:

1. **Python 3 Sandbox (Skulpt):**
   - Выполняет код изолированно в виртуальной машине внутри браузера.
   - Поддерживает стандартные структуры данных Python, функции, классы, работу со строками и математикой.
   - Защита от бесконечных циклов (`Time Limit Exceeded` > 2.5 сек) и переполнения памяти.
2. **SQL Analytics Engine (AlaSQL):**
   - Реальное выполнение реляционных SQL-запросов к таблицам данных.
   - Проверка группировок, агрегаций, условий фильтрации `HAVING` и сортировок.
3. **Строгая тестовая система:**
   - Верификация на нескольких скрытых и открытых тест-кейсах.
   - Поддержка числового допуска с плавающей точкой ($10^{-4}$) для устранения проблем округления.
   - Автоматическая изоляция тестового вывода от отладочных принтов студента.

## 🎮 Геймификация и система наград

Платформа мотивирует на регулярное обучение через прозрачные правила начисления опыта (XP):

- **Завершение урока:** `+50 XP`
- **Самостоятельное решение задачи:** `+25 XP`
- **Решение задачи с открытием подсказки:** `+10 XP` *(штраф -15 XP за просмотр эталонного кода)*
- **Правильный ответ в квизе:** `+10 XP`
- **Идеальное прохождение квиза (100%):** `+30 XP` (бонус)
- **Повторение карточки SRS:** `+5 XP`
- **Блиц / Спидран сессия:** `+25 XP` (+ комбо)
- **Сдача итогового экзамена:** `+100 XP`

> ⚠️ **Честная система подсказок:** кнопка «Эталонное решение» явно предупреждает о снижении награды до +10 XP. Если задача уже была решена самостоятельно ранее, заработанный опыт не аннулируется.

## 🚀 Быстрый старт

### Требования
- **Node.js** версии `>= 20.0.0`
- **npm** версии `>= 9.0.0`

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ruslantur77/tensormind.git
   cd tensormind
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

4. **Проверка типов и линтинг:**
   ```bash
   npm run lint
   ```

5. **Сборка production-бандла:**
   ```bash
   npm run build
   ```

## 📱 Автономность и экспорт данных

- **100% Offline First:** Все данные пользователя (стрики, опыт, статус уроков, история повторения карточек и написанный код) сохраняются локально.
- **Резервное копирование:** В настройках доступен экспорт всего прогресса в единый JSON-файл и восстановление на любом другом устройстве в один клик.
